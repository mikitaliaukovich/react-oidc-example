OIDC Test Client has moved to a desktop app

To keep client secrets and tokens out of the browser, the app no longer runs on this website. It now runs as a standalone Windows app. You'll need to enter your OIDC settings once in the new app.

Download

Download from GitHub Releases

  • OIDC-Test-Client-…-win-x64.zip: extract it to any folder and run OIDC Test Client.exe. Use this one if your company blocks the portable .exe.
  • OIDC-Test-Client-…-portable.exe: a single file with nothing to install. It unpacks itself on every start, so it opens more slowly.

The app isn't code-signed yet. If Windows SmartScreen warns you, choose More info → Run anyway.

Or run it from source

With Node.js 22.12 or later and Git installed:

git clone https://github.com/mikitaliaukovich/react-oidc-example.git
cd react-oidc-example
npm ci
npm start

Update your IdP application

Register this URL as both the redirect URI and the post-logout redirect URI:

http://localhost:8080/react-oidc-example/

The desktop app doesn't open a network port. It only uses this address inside its own window, so other programs on your machine can't reach it.
